تحديث موقع الوليد لخدمات الإنترنت

المزايا الجديدة:
1) شاشة تسجيل الدخول أصبحت أول صفحة تظهر عند فتح الموقع.
2) بعد الضغط على دخول تظهر شاشة تحميل متحركة برمز Wi-Fi.
3) إعدادات المصادقة تمنع حفظ جلسة Supabase عند إعادة تحميل الصفحة، والنموذج يطلب من المتصفح عدم حفظ بيانات الدخول.
4) ألوان الوضع الداكن أصبحت فحمية/كحلية فاخرة مع ذهبي هادئ وتباين أوضح.
5) إضافة بحث داخل نافذة كل العملاء.
6) أزرار إيقاف العميل مؤقتًا حتى تاريخ، وإلغاء الإيقاف، وحذف العميل.
7) الأرقام الظاهرة داخل الموقع تستخدم الأرقام الإنجليزية قدر الإمكان.

مهم قبل استعمال ميزة الإيقاف:
- افتح Supabase Dashboard > SQL Editor.
- شغّل محتوى الملف: تحديث_قاعدة_البيانات_للإيقاف_والحذف.sql مرة واحدة.

تحديث الموقع المنشور:
- في GitHub افتح مستودع alwaleed-internet-services.
- استخدم Add file > Upload files لرفع ملفات هذه الحزمة مع استبدال الملفات الموجودة عند الطلب.
- ارفع index.html والملفين login-background.jpg وhomepage-background.jpg وملف SQL الجديد.
- اضغط Commit changes. إذا كان Vercel مربوطًا بالمستودع فسيبدأ النشر تلقائيًا.

ملاحظة حول كلمات المرور:
- الموقع لا يحتفظ بجلسة تسجيل الدخول بعد إعادة تحميل الصفحة، ولا يحفظ كلمة المرور في ملفات الموقع أو قاعدة البيانات.
- لا يستطيع الموقع ضمان منع Chrome/Google Password Manager من عرض نافذة حفظ كلمة المرور؛ إذا ظهرت، اختر Never/عدم الحفظ، ويمكن تعطيل عرض حفظ كلمات المرور من إعدادات Chrome > Password Manager.
