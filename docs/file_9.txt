التحديث الجديد لموقع الوليد لخدمات الإنترنت

1) احتفظ بنسخة من مجلد الموقع القديم قبل استبداله.
2) افتح Supabase > SQL Editor، والصق محتوى الملف:
   تحديث_قاعدة_البيانات_للملاحظات_الثانية.sql
   ثم اضغط Run مرة واحدة. هذا الأمر يضيف notes2 فقط ولا يحذف بيانات.
3) ارفع ملفات الموقع إلى GitHub/Vercel بالطريقة المعتادة.
4) ميزة نسيت كلمة المرور ترسل رابطًا إلى البريد الإلكتروني المدخل. تأكد من إعداد Site URL وRedirect URLs في Supabase Authentication لتطابق عنوان موقعك المنشور.
5) النسخة الاحتياطية تُنزّل ملف Word بصيغة DOC متوافقًا مع Microsoft Word، ويضم بيانات العملاء والحركات المالية.
6) أكواد الخدمات المعروفة أسعارها مضافة تلقائيًا. الأكواد 83–93 لا تغيّر السعر تلقائيًا، ويمكن إدخال السعر يدويًا.

ملاحظة: اسم الخط SKR Head1 يُستخدم إذا كان مثبتًا على جهاز المستخدم؛ إن لم يكن مثبتًا فسيظهر خط بديل.
