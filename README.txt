الوليد لخدمات الإنترنت — نسخة محلية جاهزة
================================

التشغيل على جهاز Windows:
1) فك ضغط الملف كاملًا في مجلد عادي.
2) افتح مجلد sharikat_alwaleed.
3) اضغط مرتين على الملف: تشغيل_الموقع_محليًا.bat
4) ستفتح صفحة الموقع في المتصفح. اترك نافذة PowerShell مفتوحة أثناء الاستخدام.
5) اضغط «تسجيل الدخول» واستخدم حساب Supabase الذي أنشأته.

الملفات المهمة:
- index.html: الموقع كاملًا.
- config.js: إعدادات الاتصال بمشروع Supabase.
- schema.sql: جداول العملاء والمدفوعات وسياسات الوصول (لإنشاء قاعدة جديدة).
- تشغيل_الموقع_محليًا.bat: تشغيل الموقع محليًا.

مهم:
- الموقع يحتاج إنترنت للاتصال بـ Supabase.
- إذا كانت الجداول موجودة بالفعل، لا تحتاج لإعادة تشغيل schema.sql.
- إذا لم تنشئ حساب دخول بعد: Supabase Dashboard > Authentication > Users > Add user.
- لا تشارك كلمة مرور Supabase ولا تضع service_role/secret key في config.js.
- جرّب أولًا ببيانات عميل غير حقيقية قبل إدخال بيانات العملاء الفعلية.


تحديث قاعدة البيانات: شغّل ملف تحديث_قاعدة_البيانات_للتعديلات_الجديدة.sql مرة واحدة في Supabase > SQL Editor. الملف يضيف اسم الدافع الإجباري وسجل التعديلات التلقائي ويجهّز حقول العنوان والبيان والبطاقة الاختيارية. إذا كانت قاعدة البيانات موجودة بالفعل، شغّل ملف التحديث فقط ولا تعِد تشغيل schema.sql. عند إنشاء قاعدة جديدة، شغّل schema.sql أولًا ثم ملف التحديث.

الخط: يستخدم الموقع اسم الخط SKR Head1 إذا كان مثبتًا على جهازك، وإلا سيستخدم Tahoma. لإظهار الخط نفسه على كل الأجهزة والطباعة، يلزم توفير ملف الخط الأصلي بصيغة TTF أو OTF مع التأكد من حق الاستخدام.


التعديلات الجديدة في الموقع:
- زر «الإجمالي» يعرض جدول جميع العملاء مع الموبايل والمطلوب والمدفوع والمتبقي، مع إمكانية طباعة الجدول.
- زر «سجل التعديلات» يعرض التغييرات وتاريخها ووقتها وبريد حساب المستخدم الذي أجرى العملية.
- زر «تعديل» بجوار كل حركة في سجل المدفوعات، مع تحديث المبالغ والتاريخ والبيان والملاحظات واسم الدافع.
- اسم الدافع مطلوب عند تسجيل أي مدفوعة جديدة.
- الوضع الفاتح أبيض بخط أسود وتحديد أصفر، مع تكبير الخطوط في الشاشة والطباعة.


تحديثات إضافية: ملخص مالي عام بثلاثة مربعات، خلفية باهتة، تكبير الخطوط، تصدير نسخة احتياطية Excel تشمل العملاء والحركات المالية. اسم الدافع يظهر في الموقع باسم المستخدم ولا يظهر في كشف حساب الطباعة.

تحديث إضافي (أكتوبر 2026):

- زر «كل العملاء» يعرض الاسم والموبايل ورقم البطاقة والعنوان ويحدد الحقول الناقصة لكل عميل، مع اختصارات للفتح والتعديل.
- الطباعة مضبوطة بخلفية بيضاء ونص أسود وحدود واضحة.
- شاشة الافتتاح تعرض اسم «الوليد لخدمات الإنترنت» بحجم كبير مع حركة ظهور ورمز Wi‑Fi متحرك.
- يمكنك وضع صورة شاشة الدخول باسم login-background.jpg بجوار index.html، وصورة الخلفية الرئيسية باسم homepage-background.jpg في المجلد نفسه.
