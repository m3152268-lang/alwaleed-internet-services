الوليد لخدمات الإنترنت — إعداد Supabase لتفعيل الحفظ والبحث
================================================

تم وضع إعدادات الاتصال التي أرسلتها في config.js:
- Project URL مبني من معرّف المشروع الذي أرسلته.
- المفتاح المستخدم هو Publishable key الذي أرسلته.

مهم: تجهيز الملفات لا ينشئ الجداول داخل حساب Supabase تلقائيًا. يجب تنفيذ الخطوات التالية مرة واحدة في لوحة Supabase:

1) افتح https://supabase.com/dashboard وسجّل الدخول، ثم اختر مشروعك.
2) تأكد أن Project URL في Project Settings / API أو زر Connect يطابق العنوان الموجود في config.js.
3) افتح SQL Editor > New query.
4) افتح الملف schema.sql الموجود مع الموقع، وانسخ محتواه كاملًا إلى SQL Editor ثم اضغط Run.
   هذا ينشئ جدولي clients و payments وسياسات الوصول للمستخدمين المسجلين.
5) افتح Authentication > Users > Add user، وأنشئ مستخدمًا ببريد إلكتروني وكلمة مرور تعرفهما. إذا ظهر خيار تأكيد البريد، أكّد المستخدم أو عطّل تأكيد البريد للاختبار وفق إعدادات مشروعك.
6) شغّل الموقع من خادم محلي أو ارفعه إلى استضافة HTTPS. لا تفتحه كملف file:// مباشرة.
7) اضغط «تسجيل الدخول» واستخدم البريد وكلمة المرور اللذين أنشأتهما في الخطوة 5.
8) بعد الدخول، جرّب إضافة عميل ببيانات اختبار غير حقيقية، ثم ابحث عنه وأضف حركة مالية. لا تدخل بيانات عملاء حقيقية قبل التأكد من الصلاحيات والأمان.

إذا لم يعمل الاتصال:
- تأكد من أن Project URL صحيح تمامًا من لوحة المشروع.
- افتح الموقع واضغط F12 ثم Console، وابحث عن أخطاء مثل Failed to fetch أو Invalid API key.
- خطأ relation "clients" does not exist يعني غالبًا أن schema.sql لم يُنفّذ.
- خطأ Invalid login credentials يعني أن المستخدم أو كلمة المرور غير صحيحة.
- خطأ permission denied / row-level security يعني أن سياسات SQL أو جلسة تسجيل الدخول تحتاج مراجعة.

الأمان:
- لا ترسل كلمة مرور حساب Supabase.
- لا تضع service_role أو secret key في config.js. المفتاح العام publishable/anon فقط هو المناسب للواجهة.
- هذا المخطط يسمح لكل مستخدم مسجل بإدارة كل سجلات العملاء؛ أنشئ حسابات لموثوقين فقط، وراجع سياسات الصلاحيات قبل تخزين بيانات حساسة.


للتحديثات الجديدة في قاعدة موجودة: نفّذ ملف تحديث_قاعدة_البيانات_للتعديلات_الجديدة.sql مرة واحدة فقط من SQL Editor. لا تستخدم schema.sql على قاعدة قائمة.
